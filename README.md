# Security Analyst Labs

Hands-on cybersecurity labs by **Nutnicha Rungruangpiroj**, an IT Diploma Co-op student at Canadian College in Vancouver, BC, preparing for CompTIA Security+ (SY0-701).

Each lab is written as a ticket at **Northwind Wellness**, a simulated company, and follows a real analyst workflow: investigate the data, find what happened, contain it, and recommend fixes.

## Labs

| Ticket | Lab | Skills | Status |
|---|---|---|---|
| [SEC-101](./SEC-101-ssh-bruteforce) | SSH brute-force incident investigation | Linux log analysis, `grep`/`awk`, incident response, hardening | Complete |
| SEC-102 | Secure .NET web app mapped to the OWASP Top 10 | Secure coding, authentication, input validation | Planned |
| SEC-103 | Home lab with SIEM monitoring | Windows Server, Linux, log collection, alerting | Planned |

## Tools and Skills
- **Security:** log analysis, incident response, system hardening, Security+ concepts
- **Systems:** Linux, Windows Server, Azure, AWS
- **Development:** C# .NET, Blazor, REST APIs, JavaScript
